# AI CODING RULES — APPLICATION WEB LAB 1 & 2
Áp dụng cho Codex khi lập trình Exercise 1–3 và Homework 1–3.

## 01. ĐÚNG YÊU CẦU
Chỉ làm đúng task được giao, không tự thêm chức năng.

## 02. CHIA NHỎ TASK
Làm từng bước, không tự hoàn thành cả bài khi chưa được yêu cầu.

## 03. TIẾT KIỆM TOKEN
Không phân tích dài dòng; không đọc toàn bộ project nếu không cần.

## 04. CODE ĐƠN GIẢN
Ưu tiên code dễ hiểu; không thêm thư viện hoặc cấu trúc phức tạp không cần thiết.

## 05. TYPESCRIPT & REACT
Đảm bảo type safety, dùng hooks đúng cách, không để biến thừa hoặc lỗi build.

## 06. XỬ LÝ BẤT ĐỒNG BỘ
Tránh race condition; xử lý lỗi, hủy request và ngăn thao tác trùng lặp khi cần.

## 07. HIỆU NĂNG
Tránh memory leak; cleanup timer, event listener và requestAnimationFrame.

## 08. BẢO MẬT & WCAG
Chống XSS, dùng semantic HTML, hỗ trợ keyboard và WCAG 2.2 AA khi đề yêu cầu.

## 09. KHÔNG PHÁ CODE CŨ
Chỉ sửa file liên quan, giữ nguyên chức năng đang hoạt động.

## 10. KIỂM THỬ
Kiểm tra TypeScript, build và test liên quan; không nói đã test nếu chưa chạy.

## 11. AI FAILURE AUDIT
Phát hiện, ghi nhận và sửa lỗi AI; không bịa lỗi để đủ số lượng.

## 12. GIT & COMMIT
Đề xuất commit theo từng task; không tự commit hoặc push khi chưa được yêu cầu.

## 13. PHẢN HỒI NGẮN GỌN
Chỉ báo file đã sửa, nội dung sửa, kết quả test và commit đề xuất.

## 14. THỨ TỰ ƯU TIÊN
Đúng yêu cầu → Code an toàn → Không lỗi → Dễ bảo trì → Tiết kiệm token.

## QUY TẮC BỔ SUNG KHI SỬA CODE
- Đọc file liên quan trước khi sửa.
- Không tự refactor toàn bộ project.
- Không chạy lại test nhiều lần nếu không cần.
- Không tự tìm web nếu tài liệu và code hiện tại đã đủ.
- Không tự nhận code hoàn chỉnh nếu vẫn còn lỗi.
- Khi được yêu cầu xuất code để thay thế, cung cấp full file.
